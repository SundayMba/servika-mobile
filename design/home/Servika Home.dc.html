Worth deciding first
  1. Typeface. This screen is still the system font while onboarding now ships Instrument Sans. Carrying it across is the single biggest change available, and it costs nothing at runtime — the font is already bundled.
  2. The orange. The header uses #F97316; onboarding moved to the deeper #E4620A. Right now the two screens disagree.
  3. Density. Everything above the fold competes: greeting, location, bell, search, and a 182pt hero, before a single service is visible.
  4. The hero. A rotating emergency-plumbing ad sits between search and the catalogue — is that earning its place?
